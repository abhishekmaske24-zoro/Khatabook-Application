# Khatabook Application 📒

A full-stack digital ledger application that helps users manage credit and debit transactions efficiently.  
The application replaces traditional paper-based khata systems with a secure and easy-to-use online solution.

---

## 🚀 Features

- User authentication (Sign up & Login)
- Create and manage customer accounts
- Add, edit, and delete credit/debit transactions
- Automatic balance calculation
- Transaction history with timestamps
- Responsive and user-friendly interface
- Secure backend and database integration

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

---

## 🧠 How It Works

- Users register and log in securely
- Customers are added to the digital ledger
- Credit and debit transactions are recorded
- The system automatically calculates balances
- All data is stored securely in the database
- REST APIs handle communication between frontend and backend
